Quick wins for STEM content

  • Moodle: write maths in LaTeX between \( … \) and let the MathJax filter render it.
  • Word: use Insert › Equation, not images. Equations stay editable and readable.
  • Graphs: provide the data as a table and state the trend in words.
  • Code: share it as text in a code block, never as a screenshot.
  • In lectures: say equations aloud as you write them — “x equals minus b, plus or minus…”.
  • Chemistry: give structures a name or formula in the alt text, and a description of key features.
