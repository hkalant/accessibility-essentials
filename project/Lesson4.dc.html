Alt text essentials

Alt text is read aloud in place of an image. Good alt text isn’t a description of the picture — it’s the information or function the image provides in that context. The same photo can need different alt text on different pages.

  • Keep it concise — usually a sentence. Screen readers already say “image”, so skip “image of”.
  • Put complex detail (like a chart’s data) in the text or a table, with short alt text pointing to it.
  • Never put important information only in an image of text.

Late work without an extension is capped at the pass mark.

  • Left-aligned, not justified — no uneven “rivers” of white space
  • Sentence case, not capitals — word shapes stay recognisable
  • No long italic runs; bold used sparingly for the key fact
  • Short lines (about 70 characters), generous line height, and a list for the requirements

Avoid anything that flashes more than three times a second, including GIFs in slides. It can trigger seizures (WCAG 2.3.1).
